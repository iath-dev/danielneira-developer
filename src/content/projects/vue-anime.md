## About

This project is an anime browser built with Vue.js that utilizes the Jikan API, a free and open-source REST API for MyAnimeList. It provides a platform for users to search, discover, and get detailed information about anime series and movies. The interface is styled with Tailwind CSS for a clean and modern look.

[![Netlify Status](https://api.netlify.com/api/v1/badges/fa8ccc15-444c-45b8-b87b-d41fdd7e9db4/deploy-status)](https://app.netlify.com/projects/vueanime/deploys)

### Features

- **Anime Search:** Users can search for any anime by title.
- **Detailed Information:** Provides comprehensive details for each anime, including synopsis, score, episodes, and more.
- **Top Anime:** Features a section to browse the top-rated anime series.
- **Responsive Design:** The application is fully responsive, offering a seamless experience on desktops, tablets, and mobile devices.
